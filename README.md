# 112 허위신고 인터랙티브 뉴스

GitHub Pages에 바로 배포할 수 있는 정적 웹페이지입니다.

## 업로드 방법
1. 이 폴더 안의 파일을 GitHub 저장소 최상단에 업로드합니다.
2. 저장소 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/(root)`를 선택한 뒤 저장합니다.
5. 잠시 후 `https://아이디.github.io/저장소이름/` 주소가 생성됩니다.

## 파일 구조
- `index.html`: 기사 구조와 문구
- `styles.css`: 디자인과 반응형
- `script.js`: 그래프, 숫자 카운트, 인터랙션
- `assets/`: 기사 이미지

## 주의
- 기사에 제시된 수치만 사용했습니다.
- 충남청 2025년 전체 243건과 기사에 제시된 세부 처분 합계 240건 사이의 3건은 임의로 분류하지 않았습니다.
- 실제 발행 전 기사 제목, 기자명, 출처 표기와 회사 저작권 문구를 확인하십시오.
